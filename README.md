# python-user-password-validation
A simple Python OOP project demonstrating user authentication and password validation using classes, private attributes, encapsulation, and instance methods.
<br>
Topics Covered:
<br>

1. Class and Object
2. Constructor (__init__())
3. Instance Attributes
4. Encapsulation
5. Private Attributes (__password)
6. Instance Methods
7. Boolean Values (True and False)
8. Password Validation
9. String Comparison
10. Docstrings
